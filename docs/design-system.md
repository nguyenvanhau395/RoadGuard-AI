# RoadGuard AI design system

## Nền tảng

- Phong cách: Aurora UI, dashboard kỹ thuật.
- Heading: Fira Code; body: Fira Sans.
- Màu chính: `#EA580C`; màu phụ: `#0891B2`; nền: `#FFF7ED`; chữ: `#0F172A`.
- Khoảng cách chuẩn: 4, 8, 16, 24, 32, 48 và 64 px.

## Nguyên tắc giao diện

- Duy trì tỷ lệ tương phản văn bản tối thiểu 4.5:1.
- Mọi phần tử có thể bấm cần con trỏ và trạng thái focus rõ ràng.
- Dùng SVG/Lucide thay vì emoji làm icon.
- Chuyển trạng thái trong 150–300 ms; tôn trọng `prefers-reduced-motion`.
- Kiểm tra responsive tại 375 px, 768 px, 1024 px và 1440 px.

Tài liệu này thay thế thiết kế sinh tự động cũ để giữ repository chỉ chứa quy ước cần thiết cho giao diện hiện tại.
